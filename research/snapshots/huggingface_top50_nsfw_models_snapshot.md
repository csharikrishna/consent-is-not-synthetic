## Important interpretation and data-quality note

This catalogue records repositories returned by Hugging Face's text-to-image search when the query contains `nsfw`. A search match is **not** a certification that a repository is a trustworthy model, a complete standalone generator, technically reproducible, legally cleared, or actually capable of every output implied by its name.

The repository pages were opened and their visible metadata/tags were checked. This is a **repository metadata review**, not a full binary audit: the downloadable weights, hashes, file sizes, training data, and every license file have not all been independently validated. Entries with missing or ambiguous metadata are explicitly marked.

### Meaning of the fields

- **Likes:** Hugging Face likes visible at capture time; used for ranking. They are mutable and are not a quality score.
- **Downloads:** Hugging Face download count visible in the search listing. A dash means the listing did not expose a count for that entry; it does not mean zero.
- **HF parameter badge:** Parameter-count-style badge displayed in the search result (for example, `3B`). It is **not** the downloaded model file size in MB/GB. If no badge was shown, the field is `Not shown`.
- **File size:** Actual artifact size must be read from the repository's **Files** tab. It is not inferred from the parameter badge.
- **Base model:** A parent model named in a repository's tags or usage example. If it is not clear, it is marked as unverified.
- **License:** The label shown by the repository page. `Other`, `Unknown`, or a missing label is not sufficient legal permission; read the actual license text and parent-model terms.
- **Updated:** The timestamp shown by Hugging Face's search result. When the page displayed only a month/day or a relative time, the missing year is not guessed.

## 3. Model-type guide

| Type | What it means | What you need before using it |
|---|---|---|
| Full checkpoint | A complete set of model weights for a particular architecture or pipeline. | Confirm exact architecture, config files, VAE/text encoder dependencies, and license. |
| LoRA / adapter | A smaller set of learned weights applied to a compatible base model. | Download the correct parent model and use the documented adapter-loading method. A LoRA is not a standalone generator. |
| GGUF / quantized model | Weights converted or quantized into a format intended for compatible runtimes. | Confirm quantization level, loader support, memory requirements, and whether the repo is a full model or an adapter. |
| Inpainting checkpoint | A model/pipeline designed to edit or fill a selected image region. | Use an inpainting-compatible pipeline and provide the relevant mask/image inputs. |
| Image-to-video adapter | A model component for generating video from an image or conditioning input. | Use the correct video-generation base model and workflow; a text-to-image tag may be inaccurate or broad. |
| Merge / mixed package | A repository that may bundle checkpoint, VAE, text encoder, or merged components. | Inspect every file and component, upstream provenance, and each applicable license. |

### 10.2 API enrichment: generate a live audit for all 50

The script below reads the 50 repository IDs from the ranking table in this Markdown file and queries Hugging Face's public Hub API. It does **not** download model weights. It produces:

- `top50_repository_audit.csv` — one row per repository, including current likes/downloads, last update, license metadata, base-model metadata, parameter count when exposed, and total storage when exposed.
- `top50_file_manifest.csv` — one row per repository file, including file name, extension, and file size when the API returns it.
- `top50_repository_audit.json` — fuller raw-enough metadata for later analysis.

Install and run:

```bash
python -m pip install -U huggingface_hub pandas
python audit_hf_top50.py huggingface_top50_nsfw_models.md
```

Save the following as `audit_hf_top50.py` in the same folder as this Markdown file:

```python
from __future__ import annotations

import json
import re
import sys
from pathlib import Path
from datetime import datetime, timezone

import pandas as pd
from huggingface_hub import HfApi


def extract_ranked_repo_ids(markdown_path: Path) -> list[str]:
    text = markdown_path.read_text(encoding="utf-8")
    # Only parse the compact ranking table, not repeated links in later sections.
    table = text.split("## 2. Repository-by-repository notes", 1)[0]
    pattern = re.compile(
        r"^\|\s*(\d+)\s*\|\s*\[`[^`]+`\]\(https://huggingface\.co/([^/)]+/[^)]+)\)",
        re.MULTILINE,
    )
    ranked = sorted(
        ((int(rank), repo.strip()) for rank, repo in pattern.findall(table)),
        key=lambda item: item[0],
    )
    # Keep only one entry per rank and preserve the top-50 ordering.
    result = []
    seen = set()
    for rank, repo in ranked:
        if repo not in seen and 1 <= rank <= 50:
            result.append(repo)
            seen.add(repo)
    if len(result) != 50:
        raise RuntimeError(
            f"Expected 50 unique ranked repository IDs; parsed {len(result)}. "
            "Check the ranking table format before proceeding."
        )
    return result


def value(obj, key, default=None):
    if obj is None:
        return default
    if isinstance(obj, dict):
        return obj.get(key, default)
    return getattr(obj, key, default)


def as_plain_dict(obj):
    if obj is None:
        return {}
    if isinstance(obj, dict):
        return obj
    if hasattr(obj, "to_dict"):
        try:
            return obj.to_dict()
        except Exception:
            pass
    try:
        return vars(obj)
    except TypeError:
        return {"value": str(obj)}


def main():
    markdown_path = Path(sys.argv[1] if len(sys.argv) > 1 else "huggingface_top50_nsfw_models.md")
    repo_ids = extract_ranked_repo_ids(markdown_path)
    api = HfApi()

    repo_rows = []
    file_rows = []
    raw_records = []

    for rank, repo_id in enumerate(repo_ids, start=1):
        print(f"[{rank:02d}/50] Inspecting {repo_id}")
        try:
            info = api.model_info(repo_id, files_metadata=True)
        except Exception as exc:
            repo_rows.append({
                "rank_snapshot": rank,
                "repo_id": repo_id,
                "url": f"https://huggingface.co/{repo_id}",
                "audit_status": "API_ERROR",
                "error": str(exc),
            })
            continue

        card = as_plain_dict(value(info, "card_data"))
        safe = value(info, "safetensors")
        parameter_count = value(safe, "parameter_count")
        if not parameter_count:
            parameter_count = None

        siblings = value(info, "siblings", []) or []
        total_known_file_bytes = 0
        known_size_files = 0
        for sibling in siblings:
            filename = value(sibling, "rfilename", "") or ""
            size = value(sibling, "size")
            if isinstance(size, int):
                total_known_file_bytes += size
                known_size_files += 1
            file_rows.append({
                "rank_snapshot": rank,
                "repo_id": repo_id,
                "filename": filename,
                "extension": Path(filename).suffix.lower(),
                "size_bytes": size,
                "blob_id": value(sibling, "blob_id"),
            })

        repo_rows.append({
            "rank_snapshot": rank,
            "repo_id": repo_id,
            "url": f"https://huggingface.co/{repo_id}",
            "audit_status": "API_METADATA_RETRIEVED",
            "likes_current": value(info, "likes"),
            "downloads_30d_current": value(info, "downloads"),
            "downloads_all_time": value(info, "downloads_all_time"),
            "created_at": str(value(info, "created_at", "") or ""),
            "last_modified": str(value(info, "last_modified", "") or ""),
            "commit_sha": value(info, "sha"),
            "pipeline_tag": value(info, "pipeline_tag"),
            "library_name": value(info, "library_name"),
            "tags": ";".join(value(info, "tags", []) or []),
            "base_model_metadata": json.dumps(card.get("base_model"), ensure_ascii=False),
            "license_metadata": card.get("license"),
            "license_name_metadata": card.get("license_name"),
            "gated": value(info, "gated"),
            "disabled": value(info, "disabled"),
            "used_storage_bytes": value(info, "used_storage"),
            "known_file_bytes_sum": total_known_file_bytes if known_size_files else None,
            "files_with_known_size": known_size_files,
            "files_listed": len(siblings),
            "safetensors_parameter_count": json.dumps(parameter_count) if parameter_count else None,
            "config": json.dumps(value(info, "config"), ensure_ascii=False, default=str),
            "card_data": json.dumps(card, ensure_ascii=False, default=str),
        })

        raw_records.append({
            "rank_snapshot": rank,
            "repo_id": repo_id,
            "model_info": as_plain_dict(info),
        })

    pd.DataFrame(repo_rows).to_csv("top50_repository_audit.csv", index=False)
    pd.DataFrame(file_rows).to_csv("top50_file_manifest.csv", index=False)
    Path("top50_repository_audit.json").write_text(
        json.dumps(raw_records, indent=2, ensure_ascii=False, default=str),
        encoding="utf-8",
    )
    print("\nWrote top50_repository_audit.csv")
    print("Wrote top50_file_manifest.csv")
    print("Wrote top50_repository_audit.json")
    print("Snapshot generated at:", datetime.now(timezone.utc).isoformat())


if __name__ == "__main__":
    main()
```

**Important interpretation:** `downloads` in the Hub API is generally the recent 30-day count; `downloads_all_time` is a separate field when available. The script preserves both. The `blob_id` is a repository object identifier, not automatically a SHA-256 digest of the downloaded file.

### 10.3 File integrity: hash the artifacts after downloading

The Hub metadata query can list file names and sizes, but a local SHA-256 digest should be calculated from the bytes actually downloaded. This script hashes files in a local model directory:

```python
from pathlib import Path
import hashlib
import csv
import sys

root = Path(sys.argv[1] if len(sys.argv) > 1 else "./models")
output = Path("local_sha256_manifest.csv")

rows = []
for path in sorted(p for p in root.rglob("*") if p.is_file()):
    digest = hashlib.sha256()
    with path.open("rb") as handle:
        for chunk in iter(lambda: handle.read(8 * 1024 * 1024), b""):
            digest.update(chunk)
    rows.append({
        "relative_path": str(path.relative_to(root)),
        "size_bytes": path.stat().st_size,
        "sha256": digest.hexdigest(),
    })

with output.open("w", newline="", encoding="utf-8") as handle:
    writer = csv.DictWriter(handle, fieldnames=["relative_path", "size_bytes", "sha256"])
    writer.writeheader()
    writer.writerows(rows)

print(f"Hashed {len(rows)} files -> {output}")
```

Use this only after downloads have completed. Keep the repository commit SHA from the API report with the local hashes so the audit records which revision was downloaded.

### 10.4 Architecture and model-type verification

For every repository, verify these items from its model card, configuration files, and file tree:

1. **Pipeline family:** Stable Diffusion 1.x/2.x, SDXL, FLUX, Qwen-Image, Z-Image, Wan, or another architecture. Do not infer the family from the repository name alone.
2. **Artifact role:** Full checkpoint, LoRA/adapter, text encoder, VAE, quantized full model, quantized adapter, image-editing model, or image-to-video component.
3. **Parent dependency:** Exact base repository and revision/commit, not merely a family name.
4. **Weight layout:** Single file, sharded files plus index, Diffusers directory structure, or a runtime-specific package.
5. **Required components:** Text encoders, tokenizer, VAE, scheduler, processor, config, and any custom code required by the documented pipeline.
6. **Compatibility:** Supported Diffusers/Transformers version, ComfyUI nodes or other runtime, Python version, CUDA/PyTorch compatibility, and any custom loader requirement.
7. **Evidence:** Record the exact README/model-card section or config filename that supports each conclusion.

A search-result parameter badge is not enough to identify the model's true architecture or total parameter count. Prefer the Safetensors metadata, model configuration, and upstream model documentation. For adapters, record the adapter parameter count separately from the base-model parameter count.

### 10.5 Hardware and storage estimation

Do not assign a single VRAM requirement based only on a repository's name or parameter badge. Record at least three separate quantities:

- **Download/storage requirement:** Sum of the actual required files, plus room for temporary downloads, caches, and extracted files.
- **Weight memory:** Approximate memory occupied by model weights at the chosen precision.
- **Peak inference VRAM:** Weight memory plus activations, attention/workspace buffers, VAE/text-encoder memory, batch size, image resolution, and runtime overhead.

A rough *weights-only* calculation for a model with `P` parameters is:

| Weight representation | Approximate bytes per parameter | Approximate weights-only memory |
|---|---:|---:|
| FP32 | 4 | `4 × P` bytes |
| FP16 / BF16 | 2 | `2 × P` bytes |
| INT8 | 1 | `1 × P` bytes, plus quantization metadata |
| 4-bit | 0.5 | `0.5 × P` bytes, plus quantization metadata |

These are arithmetic estimates, not guaranteed runtime requirements. They do not include activations or pipeline components. Some image-generation pipelines split components across devices or offload them to system RAM. LoRA memory must be considered in addition to the base pipeline; it does not replace the base model. GGUF memory depends on the exact quantization and runtime. Record measured peak VRAM from an actual test run when possible.

For each model, fill this hardware record only after identifying the real architecture and artifacts:

| Hardware field | Value to record |
|---|---|
| Required base model(s) | Exact repository ID and revision |
| Weight format / precision | e.g. FP16, BF16, Q8_0, Q4_K_M |
| Total required download | Sum of required file sizes |
| Minimum practical GPU VRAM | Measured or sourced; state resolution and offload settings |
| Recommended GPU VRAM | Measured or sourced; state resolution and batch size |
| System RAM | Measured or sourced |
| Runtime | Diffusers / ComfyUI / other, with versions |
| Peak VRAM | Measured during a reproducible generation/editing test |
| Load time / generation time | Measured with hardware and settings recorded |
