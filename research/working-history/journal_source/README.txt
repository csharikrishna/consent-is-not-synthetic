OPEN-WEIGHT IMAGE GENERATION AND SYNTHETIC MEDIA ABUSE
Research working paper | 25 November 2026

Contents:
- journal.tex and journal.pdf: 20-page manuscript
- resources.tex and resources.pdf: numbered resource directory
- source_evidence.tex and source_evidence.pdf: annotated evidence ledger
- source_ledger.csv: machine-readable evidence register
- figures/: vector PDF charts and diagram
- build.py: generates the LaTeX, chart files and CSV using Python, NumPy and Matplotlib

To compile the existing LaTeX source, unpack the ZIP and run from its root:
  pdflatex journal.tex
  pdflatex journal.tex
  pdflatex resources.tex
  pdflatex resources.tex
  pdflatex source_evidence.tex
  pdflatex source_evidence.tex
A standard TeX Live distribution with the newtx, microtype, graphicx, booktabs,
tabularx, xcolor, caption, enumitem, fancyhdr, hyperref and xurl packages is needed.
The figures are provided, so Python is not needed merely to compile.

This is a targeted evidence review, not a peer-reviewed article, complete model
census, independent safety audit or legal opinion. Add author details and verify
legal sources and findings before formal submission. All figures are original
redrawings or analytic diagrams; external image download failed.
